# 🛡️ No Mercy для Android

Официальное приложение **No Mercy**. Войдите в аккаунт и подключайтесь одной кнопкой.

## 📥 Скачать

👉 **[Скачать последнюю версию (APK)](https://github.com/zuhra322/nomercy-android/releases/latest/download/nomercy-android.apk)**

## 📲 Установка за 4 шага

1. **Нажмите на ссылку выше**. Файл `nomercy-android.apk` скачается на телефон.
2. **Откройте скачанный файл**: нажмите на уведомление о загрузке или найдите файл в папке «Загрузки».
3. Если телефон пишет *«Установка из неизвестных источников запрещена»*, нажмите **«Настройки»**, включите **«Разрешить из этого источника»** и вернитесь назад.
4. Нажмите **«Установить»**, затем **«Открыть»**.

## 🔑 Первый запуск

1. Войдите через **логин и пароль** или через **Telegram**.
2. Нажмите большую кнопку **подключения**.
3. Android спросит разрешение на подключение. Нажмите **«ОК»**.

Готово ✅ Вход сохраняется, поэтому заново вводить данные не нужно.

## ❓ Если что-то не так

| Проблема | Что сделать |
|---|---|
| «Приложение не установлено» | Удалите старую версию No Mercy и установите заново |
| Нет кнопки «Установить» | Разрешите установку из неизвестных источников (шаг 3) |
| Не подключается | Проверьте, что подписка активна, и попробуйте другой сервер |
| Медленно работает | Выберите в приложении другой сервер |

Остались вопросы? Напишите в нашу поддержку в Telegram.

## 🔄 Обновление

Скачайте новую версию по той же ссылке и установите её поверх старой. Если появилась ошибка, удалите старую версию и установите новую.
